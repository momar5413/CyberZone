# CyberZone — نظام إدارة صالة الألعاب

تطبيق ويب عربي متكامل لإدارة صالات البلايستيشن والكمبيوتر والـ VR: مؤقتات حيّة لكل جهاز، حساب دقيق للتكلفة، حجوزات، بوفيه ومخزون، إيصالات، وتقارير. يعمل مباشرة في المتصفح دون خادم أو قاعدة بيانات، ويمكن تثبيته كتطبيق على الهاتف أو الكمبيوتر ويعمل دون إنترنت.

## الميزات

**الصالة (الشاشة الرئيسية)**
- لوحة ملخّص في الأعلى: عدد الأجهزة المتاحة والمشغولة والتي ينتهي وقتها (تعمل كفلتر بضغطة)، وما هو قيد التحصيل، ودخل اليوم.
- بطاقة لكل جهاز بعدّاد نقطي كلوحات النتائج وحالة واضحة: متاح، يلعب، وقت مفتوح، ينتهي قريباً، انتهى الوقت، متوقف، صيانة.
- عرض بطاقات أو قائمة مضغوطة للصالات الكبيرة.
- بدء سريع بضغطة واحدة من البطاقة (وقت مفتوح، 30 دقيقة، ساعة، ساعتان)، مع إضافة الاسم لاحقاً.
- مؤقت حيّ: عدّ تصاعدي للوقت المفتوح، وعدّ تنازلي مع شريط مقطّع للمدة المحددة، وعدّاد تجاوز بعد انتهائها.
- الحساب الجاري لكل جلسة يتحدّث كل ثانية (الوقت + طلبات البوفيه).
- تنبيه صوتي ورسالة قبل انتهاء الوقت وعند انتهائه، مع إشعارات النظام اختيارياً، وعدد الأجهزة المنتهية في عنوان الصفحة.
- تمديد الوقت، تحويل الجلسة المفتوحة إلى مدة محددة والعكس، إيقاف مؤقت (لا يُحتسب الوقت أثناءه).
- نمط فردي/زوجي بسعرين مختلفين، ونقل الجلسة لجهاز آخر مع احتساب كل جزء بسعر جهازه.
- تصفية حسب الحالة والنوع وبحث باسم الجهاز أو اللاعب.

**الحساب والدفع**
- وحدة حساب قابلة للضبط (دقيقة، 5، 10، 15، 30، ساعة) مع فترة سماح وحد أدنى للجلسة.
- تقريب أجرة الوقت (للأقرب أو لأعلى) إلى 50 أو 100 أو 500 أو 1000.
- في الجلسات المحددة تُحتسب المدة المحجوزة كحد أدنى، مع خيار احتساب الوقت الفعلي فقط.
- خصم، طريقة الدفع (نقدي/إلكتروني)، المبلغ المدفوع مع أزرار مبالغ سريعة، والباقي للزبون.
- «تراجع» بعد كل عملية (إنهاء جلسة، بيع، حذف، إلغاء) بدل نوافذ التأكيد.
- إيصال مرقّم قابل للطباعة (بعرض 80 مم) أو النسخ كنص.

**الحجوزات**
- حجز جهاز محدد بموعد ومدة، مع كشف التعارض مع الحجوزات الأخرى ومنعه.
- ظهور الحجز على بطاقة الجهاز قبل الموعد، وتنبيه عند بدء جلسة تتقاطع مع حجز.
- بدء الجلسة من الحجز مباشرة ببيانات الزبون والمدة، وتسجيل الإلغاء وعدم الحضور.

**البوفيه والمخزون**
- منتجات بفئات (مشروبات باردة وساخنة، سناكات، وجبات) وأسعار ومخزون اختياري.
- إضافة الطلبات إلى حساب جلسة، أو بيع مباشر من سلة مستقلة.
- خصم المخزون تلقائياً وتنبيه عند انخفاضه، ومنع البيع عند نفاده.

**الصندوق والورديات**
- فتح وردية برصيد افتتاحي، ومتابعة المبلغ المفروض وجوده في الصندوق لحظياً.
- تسجيل المصاريف (أمبيرات، مازوت، إنترنت، ثلج…) والسحوبات والإيداعات.
- إغلاق الوردية بعدّ النقد ومعرفة الزيادة أو النقص، وتقرير وردية قابل للطباعة، وسجل الورديات السابقة.

**التقارير**
- فترات جاهزة (اليوم، أمس، 7 أيام، 30 يوماً، هذا الشهر، الكل) أو فترة مخصصة.
- إجمالي الإيراد، المصاريف، الصافي، الخصومات، إيراد الوقت والبوفيه، عدد الجلسات، ساعات اللعب، طرق الدفع.
- رسوم بيانية: الإيراد اليومي (أو حسب الساعة ليوم واحد)، الإيراد حسب الجهاز، ساعات الذروة، الأكثر مبيعاً.
- أفضل الزبائن، التوزيع حسب نوع الجهاز، وسجل كامل للعمليات مع البحث وإعادة عرض الإيصال.
- تصدير CSV يفتح بالعربية بشكل صحيح في Excel.

**الإعدادات والبيانات**
- «جهّز صالتي»: إدخال عدد الأجهزة من كل نوع وأسعارها دفعة واحدة.
- اسم الصالة، رمز العملة، نص الإيصال، أنواع الأجهزة وأسعارها، الأجهزة وأسعارها الخاصة وترتيبها كما في الصالة.
- اختصارات لوحة المفاتيح: الأرقام 1–6 للتنقل، `/` للبحث، `?` لقائمة الاختصارات.
- سمة داكنة وفاتحة أو حسب النظام.
- نسخة احتياطية (JSON) واستعادتها، ومسح العمليات للبدء من جديد.

## التشغيل محلياً

لا يحتاج التطبيق أي تثبيت. افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً محلياً لتفعيل وضع عدم الاتصال:

```bash
npx serve .
# أو
python3 -m http.server 8080
```

عند أول تشغيل تظهر بيانات تجريبية لتجربة كل الميزات. اضغط **«جهّز صالتي»** وأدخل عدد أجهزتك وأسعارها لتبدأ من الصفر.

## النشر

التطبيق ملفات ثابتة فقط، فيمكن نشره على أي استضافة مجانية.

### GitHub Pages
1. ادمج هذا الفرع في `main` (أو اختر الفرع مباشرة في الخطوة التالية).
2. من المستودع: **Settings ← Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة يصبح الموقع متاحاً على: `https://momar5413.github.io/CyberZone/`

### Netlify
اسحب مجلد المشروع إلى [app.netlify.com/drop](https://app.netlify.com/drop)، أو اربط المستودع واترك أمر البناء فارغاً ومجلد النشر `.`.

### Vercel
استورد المستودع من [vercel.com/new](https://vercel.com/new) واختر **Other** كإطار عمل دون أمر بناء.

## تطبيقات الموبايل وسطح المكتب

نفس الواجهة مغلّفة كتطبيقات حقيقية، وكلها تُبنى من هذا المستودع:

| المنصة | التقنية | الملف |
|---|---|---|
| أندرويد | [Capacitor](https://capacitorjs.com) | `CyberZone-android.apk` |
| ويندوز 10 و11 | [Tauri](https://tauri.app) | `CyberZone_x.y.z_x64-setup.exe` |
| ماك (Intel وApple Silicon) | Tauri | `CyberZone_x.y.z_universal.dmg` |

**التنزيل:** عند كل دمج في `main` يبني GitHub Actions كل الملفات تلقائياً وينشرها في صفحة **Releases** بالمستودع.

داخل التطبيقات:
- تعمل دون إنترنت، والخطوط مضمّنة.
- «تصدير CSV» و«نسخة احتياطية» تفتح نافذة الحفظ على الكمبيوتر، وقائمة المشاركة على أندرويد (حفظ في الملفات، Drive، واتساب…).
- بيانات كل جهاز محفوظة عليه وحده. انقلها بين الأجهزة بالنسخة الاحتياطية.

### البناء محلياً

```bash
npm install
npm run android:apk      # يحتاج JDK 21 وAndroid SDK — الناتج في android/app/build/outputs/apk/debug/
npm run android:open     # فتح المشروع في Android Studio
npm run desktop:dev      # تشغيل برنامج سطح المكتب للتجربة (يحتاج Rust)
npm run desktop:build    # بناء برنامج التثبيت للنظام الحالي
```

## أين تُحفظ البيانات؟

تُحفظ كل البيانات في متصفح الجهاز نفسه (`localStorage`)، ولا تُرسل إلى أي خادم. هذا يعني:
- البيانات خاصة بالمتصفح والجهاز المستخدم؛ استخدم جهاز الكاشير نفسه دائماً.
- مسح بيانات المتصفح أو التصفح الخاص يحذفها، لذا **صدّر نسخة احتياطية بانتظام** من الإعدادات.
- لنقل البيانات لجهاز آخر: صدّر نسخة احتياطية ثم استعدها على الجهاز الجديد.
- فتح التطبيق في أكثر من تبويب على الجهاز نفسه يبقى متزامناً.
